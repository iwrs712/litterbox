Litterbox

架构全景

控制面负责编排，数据面负责执行；两条链路在 Sandbox Pod 汇合。

控制面 数据面 异步 基础设施

控制面

API 只写期望状态：模板和 Webhook 放 ConfigMap，沙箱写 SandboxTemplate、SandboxWarmPool、SandboxClaim。上游控制器负责 Pod、PVC 和预热池。

数据面

所有交互都经 envd：process 执行命令，files 读写 workspace，PTY/ACP 提供终端。代理只做鉴权、Pod IP 解析和流式转发。

暂停与 TTL

TTL 由 API 内的扫描任务处理；到期把沙箱设为 operatingMode=Suspended：删除 Pod、保留 PVC。resume 重建 Pod 并挂回同一 PVC。
