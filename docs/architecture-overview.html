创建沙箱（无预热池）

  1. API 合并 workspace：全局配置 → 模板 → 请求
  2. 写 SandboxClaim
  3. agent-sandbox 创建 PVC 和 Pod，回写 status
  4. API 等 Pod ready 后返回

从预热池分配

  1. 创建 SandboxClaim，领取预热或冷启动
  2. 领取后 claim 成为对外 sandbox id
  3. 立即返回已就绪沙箱
  4. SandboxWarmPool reconciler 补回 replicas

envd 数据面

  1. E2B SDK 走 49983-{id}.sandbox.runlet.cn
  2. Dashboard 走 /api/v1/sandboxes/{id}/envd
  3. envd proxy 查 ready Pod IP（缓存 5s）
  4. 转发到 PodIP:49983，不经过控制器

暂停 · TTL · 删除

  • 暂停：operatingMode=Suspended，删 Pod 留 PVC
  • TTL：API 扫描到期后暂停，PVC 不动
  • 恢复：operatingMode=Running 重建 Pod，PVC 数据保留
  • 删除：删 Claim，级联回收 Sandbox、Pod 和 PVC
